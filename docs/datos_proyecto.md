# Datos del proyecto — PcSaurios

## 1. Datos generales

* **Nombre del proyecto:** PcSaurios
* **Tipo:** Página web comercial (Front-End)
* **Propósito:** Centralizar y presentar de manera organizada el catálogo de productos coleccionables, accesorios y productos personalizados, facilitando la consulta de información y la gestión de solicitudes.

---

## 2. Descripción y problemática

PcSaurios comercializa productos orientados a coleccionistas y aficionados: photocards, polaroids, sleeves, postales, fotografías, álbumes, figuras y artículos personalizados. 

Anteriormente, la información comercial se distribuía a través de publicaciones en redes sociales y conversaciones directas, dificultando que los visitantes conocieran de forma unificada el catálogo, los precios, los estados de disponibilidad y la logística de envíos internacionales. La página web busca resolver esta dispersión mediante una plataforma centralizada y accesible desde cualquier navegador.

---

## 3. Público objetivo

* Coleccionistas de photocards y artículos de K-pop y otros artistas.
* Aficionados que buscan accesorios de protección (sleeves, binders, toploaders).
* Compradores interesados en papelería, postales, fotografías y productos personalizados.
* Responsables y administradores de PcSaurios.

---

## 4. Tecnologías del proyecto

* **Front-End:** HTML5 semántico, CSS3 personalizado, Bootstrap 5.3 y JavaScript nativo (Vanilla JS).
* **Diseño:** Responsivo (móviles, tabletas y computadoras), accesible y optimizado para tiempos de carga eficientes.
* **Implementado en entregas posteriores:** Back-End MySQL, autenticación de usuarios, roles y panel administrativo; siguen fuera de alcance las pasarelas automáticas de pago, el cálculo automático de envíos y el seguimiento de guías.
